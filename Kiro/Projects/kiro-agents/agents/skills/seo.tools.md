## Additional Capabilities

### Analysis Scope
- Meta tag optimization (title, description, OG tags)
- Schema markup generation (JSON-LD: FAQPage, Organization, Product)
- Sitemap and robots.txt generation
- Core Web Vitals recommendations
- AEO (Answer Engine Optimization) for AI search visibility
- Content structure optimization (heading hierarchy, keyword placement)

### Access
- Read-only access to website source for analysis
- Generates code blocks for implementation by frontend agent
